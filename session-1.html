Session 1

Session 1 (proposed): GPT Image 2 + brand book + image editing.

A suggested first session to get you started. One workflow, end to end: generate jewellery images with GPT Image 2, lock them to a brand book so the look stays consistent, then edit and refine in Canva. Browse the tutorial menu to see all available sessions and pick what fits your priorities.

What we'll cover.

  • GPT Image 2 prompts. Walk through the prompt dossier, generate a few hero shots on real Kura pieces.
  • Transform images. Use GPT Image 2's edit endpoint to drop a clean Kura product photo in and have the model recompose the scene around it. The piece stays identical, only the environment changes.
  • Brand book. Generate a one-page brand book from your existing aesthetic so every future AI image inherits the same palette, typography, and tone.
  • Brand identity lock. Use the brand book as a reference image alongside your prompt to keep outputs on-brand instead of generic.
  • Image editing. Pull AI outputs into Canva Magic Layer to clean up metal edges, swap backgrounds, fix small artefacts, and finalize for the feed.

Brand book — generate.

The first half of the brand-book workflow. Upload a reference image that captures the Kura aesthetic you want to commit to. The model reads that image and outputs a one-page brand book with palette, typography, and tone of voice. Save that brand book PNG — it becomes the reference for every future generation.

Create a clean, modern brand book mood board using the provided image as the core inspiration. Place the brand logo at the top center in a style that matches the mood of the image. On the left side, add a section titled "Style Aesthetic:" with the subtitle "What we aim our style to look like". Present the provided image as a neat grid or collage that reflects its natural style and tone. On the right side, create structured brand book sections. Let all visual choices be inferred from the uploaded image: Font: Show two font examples labeled "Headlines" and "Subheadlines". Choose font styles that match the character, mood, and feeling of the provided image. Main color palette: Generate a set of color swatches directly based on the dominant and supporting colors found in the provided image. Label each swatch with simple names that match the tones. Tone of voice: Create a short list of brand voice traits that reflect the emotions, attitude, and personality suggested by the provided image. Keep the overall layout minimal, balanced, and clean with gentle spacing and simple black text. The final result should look like a polished brand book page that adapts itself entirely to the style of the uploaded image.
How to use. Upload one Kura reference image (a recent campaign shot, a hero piece on velvet, or a mood-board photo that feels right). The model returns a brand book page. Download that PNG. From now on, attach it alongside any image prompt so the output lands in the same visual world.

Brand book — apply.

The second half. Once you have a brand book PNG, you can pass it together with any existing image (a product shot, a thumbnail, an ad creative) and have the model restyle the source into the brand. Composition stays, palette and feel transfer over.

Restyle the source image using the brand book as the visual reference. Keep the original layout, composition, and text hierarchy intact. Pull every visual choice from the brand book: colors, typography, mood, and spacing. Recolor all elements inside the source (clothing, props, lighting, backgrounds) to fit the brand palette.
The recolor clause matters. Without "Recolor all elements inside the source...", the model preserves the original colors of things in the photo (a red dress stays red, an orange background stays orange), which defeats the workflow. Keep that line in.
